How Tomcat Works：从 Socket 到 Catalina

这套教程整理自 Budi Kurniawan 与 Paul Deck 的经典著作《How Tomcat Works》。原书从一个三个类的 Web 服务器开始， 一章加一个零件，最后拼出完整的 Tomcat 4/5 Servlet 容器（代号 Catalina）。 这里保留原书的全部主线和关键源码，配上大量示意图，并为每一章提供一份可以直接运行的 Java 17 + Tomcat 11 对照代码，让你看清二十年前的设计在今天变成了什么样。

在原书 20 章之外，还补充了原书之后的 8 章（RequestDispatcher、静态资源与编码、NIO 连接器、异步 Servlet、 Spring Boot 的启动方式、HTTP/2 与 WebSocket、虚拟线程、运维），4 章设计篇（架构原则、扩展点、设计模式、 并发与演进——可以直接用到你自己的 Java 项目里），以及综合实战和附录。

Servlet 容器到底做什么

不管多复杂，一个 Servlet 容器为每个 Servlet 请求做的事情只有三件：

📥

① 创建请求对象

把 HTTP 报文解析成 HttpServletRequest：参数、请求头、Cookie、查询串、URI……

📤

② 创建响应对象

准备一个 HttpServletResponse，Servlet 往里写的内容最终变成 HTTP 响应。

⚙

③ 调用 service

找到对应的 Servlet，调用它的 service(request, response)。

Catalina 据此分成两大模块：连接器负责前两件事，容器负责第三件事——当然，「调用 service」之前它还要加载 Servlet、认证用户、更新会话……这些工作又分给了载入器、Realm、管理器等一系列组件。

章节目录

前五个部分对应原书 20 章：先从零写一个 Web 服务器和最简单的 Servlet 容器，再做出 Tomcat 4 的默认连接器，然后逐个讲解容器用到的组件，接着是四种标准容器的实现，最后是启动、部署和管理。

第六部分补上原书之后二十年的变化；第七部分（设计篇）把散落在各章的设计决定提炼成可以带走的原则；第八部分用一个完整的请求追踪和一个插件化任务调度器把全书串起来；附录给出学习路线、术语表和自测题。

每一章怎么读

每一章都按同样的结构组织：

  1. 原理与原书代码：用图解释这一章的组件是做什么的、为什么这样设计，并摘录原书和 Tomcat 4/5 的关键源码。
  2. Java 17 对照版：同一功能的现代写法。通常包含两部分——一个和原书类一一对应的「迷你 Catalina」实现（接在前几章的代码上逐步长大），以及用嵌入式 Tomcat 11 真实 API 写出的同等程序。
  3. 运行与验证：所有输出都来自真实运行，你可以照着命令复现。
  4. 设计要点：这一章里可以带到别的项目的设计决定，按「做法 → 取舍 → 替代方案 → 还能用在哪」整理，并链接到设计篇。
  5. 小结与动手练习。
ⓘ 需要什么前置知识

会写 Java、知道类和接口、听说过 Servlet 就够了。每章开头都会补充需要的背景知识（HTTP、类加载器、线程交接、XML 解析……）。Java 17 对照代码会顺带介绍用到的新语法：record、var、switch 表达式、模式匹配 instanceof、文本块、java.time、java.util.concurrent 等。

运行 Java 17 对照代码

对照代码位于仓库的 java17/ 目录，是一个普通的 Maven 工程，主要依赖是 tomcat-embed-core（它自带 jakarta.servlet 6.1 API、Catalina、Digester、JULI、modeler），第 26 章另加 tomcat-embed-websocket，测试用 JUnit 5。

# 需要 JDK 17 或更高版本、Maven 3.6+
cd java17
./run.sh ch01.HttpServer                 # 第 1 章：最简单的 Web 服务器
./run.sh ch05.startup.Bootstrap2         # 第 5 章：迷你容器（Context + 两个 Wrapper）
./run.sh ch05.tomcat.EmbeddedBootstrap   # 第 5 章：同样的结构跑在 Tomcat 11 上
bin/startup.sh && bin/shutdown.sh        # 第 17 章：用脚本启停整个迷你 Tomcat
目录内容
src/main/java/modern/chNN/第 NN 章的代码；startup/ 是启动类，tomcat/ 是 Tomcat 11 版本
src/main/java/modern/common/各章共用的工具：动态代理外观、Servlet 接口的默认实现等
src/main/java/modern/design/设计篇（第 29～32 章）的代码；design/kit/ 是可以直接复用的生命周期、组合组件、管道、插件类加载器
src/main/java/modern/scheduler/第 34 章的插件化任务调度器
src/main/java21/需要 JDK 21 的代码（第 27 章虚拟线程），由 Maven profile 在 JDK 21+ 上自动编译
src/test/java/JUnit 5 测试，mvn verify 运行；GitHub Actions 在 JDK 17 和 21 上各跑一遍
webroot/示例 Servlet 的源码（jakarta 版），由 compile-servlets.sh 编译
myApp/、webapps/app1/按标准目录结构组织的 Web 应用（第 8 章起使用）
conf/、bin/、etc/server.xml、tomcat-users.xml、启动脚本、Digester 示例 XML

二十年间变了什么

原书基于 J2SE 1.4、Servlet 2.3/2.4 和 Tomcat 4.1/5.0。下表是读这本书时最值得留意的变化，各章正文中还有更详细的说明：

主题原书（2004）今天（Java 17 / Tomcat 11）
Servlet API 包名javax.servletjakarta.servlet（Jakarta EE 9 / Tomcat 10 起）
连接器线程模型阻塞 IO，一个连接一个处理器线程（第 4 章）NIO/NIO2；Java 21 可用虚拟线程
管道ValveContext.invokeNext()阀组成链表，getNext().invoke()（第 5 章）
生命周期每个组件自己维护 startedLifecycleBase + LifecycleState 状态机（第 6 章）
日志Logger / FileLoggerJULI（基于 java.util.logging）（第 7 章）
后台任务每个组件一个线程共享后台线程 → 工具线程池（第 12 章）
SingleThreadModel容器要维护实例池Servlet 6.0 已删除（第 11 章）
Mapper / Deployer 接口容器级的 Mapper，Host 实现 Deployer连接器阶段统一映射；部署逻辑全部在 HostConfig（第 12、18 章）
Digester、ModelerCommons Digester / Commons Modeler并入 Tomcat：org.apache.tomcat.util.digester / .modeler（第 15、20 章）
JMX需要单独的实现（MX4J）JDK 内置，平台 MBean 服务器（第 20 章）
安全管理器可选的沙箱Java 17 废弃，Tomcat 11 已移除支持
配置方式只有 web.xml注解、web-fragment、ServletContainerInitializer；Spring Boot 用代码启动嵌入式 Tomcat（第 25 章）
异步与协议同步阻塞的 HTTP/1.1异步 Servlet、非阻塞 IO、HTTP/2、WebSocket（第 24、26 章）

关于本教程

本教程是对原书的学习笔记与再创作：章节结构、示例程序和讲解主线来自原书；示意图、Java 17 / Tomcat 11 对照代码、「原书之后的变化」以及练习为新增内容。原书配套源码（HowTomcatWorks/ 目录）中包含 Tomcat 4.1.12 的源代码，其版权归 Apache 软件基金会所有。建议配合原书一起阅读。

💡 推荐的阅读顺序

第 1–5 章是基础，务必按顺序读并亲手跑一遍代码；第 6–10 章是容器的各个组件，彼此相对独立；第 11–14 章把组件拼成标准容器；第 15–20 章讲配置、启动、部署和管理。读完第 17 章后，再回头看一遍首页的全景图，你会发现每个方框你都亲手写过一个。
